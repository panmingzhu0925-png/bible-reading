生成时间：2026-10-17。核验脚本为 `image-work/check-family-integration-v15.cjs`；机器可读结果见 `output/integration-v15-report.json`。此文件记录本地集成核验，不代表已发布。

## 已核验范围

静态检查覆盖主网页七个入口、人物列表与历史分组保留、17 套家谱的跨页目标及节点端点、默认竖向与全部展开、十二支派选择器、两份福音家谱导航、马利亚母系释经说明和约瑟非生父语义。生产资源引用已按 GitHub Pages 的 `/bible-reading/` 子目录解析，检查 v15 脚本、CSS 导入、相对链接、manifest 的启动地址和作用域。

Service Worker 检查通过 Node.js 的 Mock CacheStorage、Mock Fetch 和模拟生命周期事件执行，覆盖预缓存文件清单、安装请求 reload、旧缓存清理、别站缓存保留、17 个家谱视图的查询导航离线回退、原图页面及人物索引查询回退、资源缓存优先、导航网络优先、同源其他项目隔离和 POST 请求隔离。

这批核验没有启动真实 Safari，没有执行 iPhone“添加到主屏幕”、触摸缩放或浏览器管理的实际离线缓存，因此不能写成“已通过 Safari/PWA 实机测试”。Mock 也不模拟存储配额、系统回收、旧浏览器版本或真实网络/CDN 更新时序。上线后仍须在正式网址验证浏览器载入、缓存更新和实际离线行为。

## 可重建与发布建议

`node family-tree/build-viewer.cjs` 从已审核的预览模板和 JSON 构建正式查看器。生成文件不含外部 CDN 依赖；正式运行数据为 `family-tree/tree-data.js`。旧 `family-tree/data.js` 不再由新页面加载。

`output/publish-files-v15.json` 列出建议提交的运行文件、构建源、核验脚本和资料审阅文档，以及应原样保留的两张图片、图标、manifest 和 ECharts。执行 `node image-work/build-publish-list-v15.cjs` 可刷新目录中已完成的构建源清单。发布脚本应重新读取远端 HEAD，以非强制方式提交，不能复用旧发布脚本保存的 HEAD。

家谱含人物、未具名角色、族群及班次，同一人物还可能跨页重复。17 个视图的档案条目不能作为全圣经不同人物数量，也不能据此宣称全部人物均已收录。
