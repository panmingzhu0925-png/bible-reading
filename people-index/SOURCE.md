# 人物经文索引的来源和范围

本目录的 `data.js` 与 `stepbible-data.json` 是 **STEPBible TIPNR 人名经文索引的筛选格式转换**。作者为 STEPBible / Tyndale House Cambridge，许可为 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。原始数据应从[作者 GitHub 仓库](https://github.com/STEPBible/STEPBible-Data/tree/master/Proper%20Nouns)取得。本项目不重新分发完整原始数据库。

使用的原文件：`TIPNR - Translators Individualised Proper Names with all References - STEPBible.org CC BY.txt`，下载核查日期 2026-10-17；Git blob `01c6ea0ca3098f53783f1994106d7e4b06566a4c`；SHA-256 `2f4695da58e7ac5a9e477c1bcb590d52bf3e119d4e640844ae7f45d218c204d8`。构建脚本检查完整原文件的 Git blob 散列，避免无声换版。

## 本次导入了什么

仅提取源文件 `PERSON(s)` 分类中 `Male` / `Female` 且具有具名、译名或称谓形式和66卷经文引用的记录，共 **2,995 条索引记录**、20,399 个去重的人物—节号关联。旧约经文出现2,734条，新约出现374条，其中113条跨两约；这两个数字有重叠。

记录 ID 沿用源索引的个体化 Strong 标识。英文名和别名不机器翻译成中文；同名不同 ID 分开显示。父母、配偶、后裔、自动简介、人工简介和 AI 文章字段均未导入。家谱连线不从此索引自动生成。

中文人物导读由122篇补充到222篇，17个家谱视图的档案另行保留。它们与英文索引存在交集，且家谱包括未具名角色、族群和班次，**不能把这些条目数量相加当作圣经独立人物总数**。

## 排除和保留的边界

- 源 `PERSON(s)` 共3,129条，其中75条为群体，不计作个人；3,054条 `Male` / `Female` 中59条未导入。58条没有可用的具名形式；另有一条 `Unnamed#1@Mat.1.15 / G0000` 虽被源标成 `Named`，但原说明明确是为补齐世代插入的假设人物，本项目予以排除。59条包括未具名亲属、为连接家谱而假设的匿名角色、只见于七十士译本的名字，以及被按民族或群体记录的形式。
- `PLACE+PERSON` 的10条是地点和人物辨识不明确的记录，未直接算作具名个人。这是待核查边界，不表示相关经文中绝无人物。
- 地点、族群、神与灵体名称、节期、乐曲、语言等其他类别未导入。它们不属于本次“人类人物”计数。
- 原索引有不同译本、抄本异文和个体归并判断。本项目保留该索引的标识和归并，不把它们提升为圣经明说的事实，也不声称2,995就是最终、无争议的圣经人物总数。
- 已见具体例子：源 `Demetrius / G1216` 把《使徒行传》19:24、38的银匠底米丢与《约翰三书》12节的低米丢归在一条记录。圣经没有直接确认二者为同一人。本索引增加 `identityNote` 人工核查警注；中文导读分别保留，不自动合并。
- 未具名角色没有系统收录；少数来源按称谓列为具名的记录（例如法老、示巴女王、迦特的高大之人）沿用来源称谓，不能据此说未具名人物已经齐全。
- `hasVariants` 表示来源包含异文、译义或标记差异；具体仍应查来源与圣经正文。别名中的部分英文是称谓或译本差异，未必都是个人本名。
- 经文采用源索引的标准英文章节编号；诗篇题注的 `verse=0` 显示为“题注”。链接打开和合本该章以供核对，译名和题注编号可能有差别。

## 格式转换明细

读取具名、不同拼写、希腊语、亚兰语与变体形式中明列的完整经文栏；不采用 `Total` 栏的 `ff` 等缩写经文。忽略 `Group`、`Mentioned` 和 `LXX addition` 形式。把同节词语重复出现的 a/b 标记合并为一个节号；把 `Num.13.8,16` 明确展开为13:8、13:16。原数据不经推断补充经文。

`stepbible-exclusions.json` 保存排除条目的原标识与理由，供维护核查。构建脚本位于 `build-step-index.cjs`；开发者先从作者仓库下载上述固定版本，再运行：

```powershell
node people-index/build-step-index.cjs <原始TIPNR文本路径>
node people-index/check-step-index.cjs
```

这是一套有出处的缺漏检查基准和经文检索入口；后续仍需逐条核对中文译名、同名身份及跨家谱跳转，逐步扩展中文人物知识库。
